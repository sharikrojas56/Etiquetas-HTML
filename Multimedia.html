Multimedia

HTML permite integrar distintos tipos de contenido multimedia en una página web, como imágenes, audio y video. Para esto existen etiquetas específicas que permiten insertar y controlar estos elementos de forma sencilla. El uso de multimedia hace que las páginas sean más dinámicas e interactivas, mejorando la experiencia del usuario

Introducción a las Etiquetas de Tablas en HTML

La multimedia en HTML permite incorporar recursos como imágenes, sonidos y videos dentro de una página web, haciendo que el contenido sea más dinámico, visual e interactivo. Estos elementos enriquecen la experiencia del usuario y facilitan una mejor comprensión de la información. Para integrar este tipo de contenido, HTML5 ofrece etiquetas específicas que permiten insertar, reproducir y controlar archivos multimedia directamente desde el navegador, sin necesidad de herramientas externas. A continuación, veremos las principales etiquetas utilizadas para trabajar con multimedia en HTML:

  • <img>
  • <audio>
  • <video>
  • <source>
  • <iframe>

<img>

La etiqueta <img> se utiliza para insertar imágenes dentro de una página web. Es un elemento vacío, lo que significa que no necesita etiqueta de cierre. Permite mostrar fotografías, ilustraciones, logos o cualquier recurso gráfico.

Es obligatorio utilizar el atributo src, que indica la ruta de la imagen, y el atributo alt, que proporciona un texto alternativo en caso de que la imagen no cargue y mejora la accesibilidad para lectores de pantalla. También se pueden usar atributos como width y height para definir su tamaño.

<audio>

La etiqueta <audio> permite insertar y reproducir archivos de sonido directamente en el navegador, sin necesidad de programas externos. Es ideal para música, podcasts, efectos de sonido o contenido educativo.

El atributo controls agrega botones de reproducción, pausa y volumen. También puede incluir atributos como autoplay (reproducción automática) y loop (repetición continua). Dentro de esta etiqueta se usa <source> para definir diferentes formatos y mejorar la compatibilidad.

Ejemplo de uso:

Código HTML:
                           <audio controls>
                           <source src="audio/musica.mp3" type="audio/mpeg">
                            Tu navegador no soporta el elemento de audio.
                           </audio>

<video>

La etiqueta <video> permite insertar y reproducir archivos de video directamente en el navegador. Es utilizada para mostrar contenido audiovisual como tutoriales, presentaciones o material educativo.

El atributo controls agrega los botones de reproducción, pausa, volumen y pantalla completa. También puede incluir atributos como autoplay (reproducción automática), loop (repetición continua) y width o height para definir el tamaño del reproductor.

Ejemplo de uso:

Código HTML:
                           <video width="400" controls>
                           <source src="video/ejemplo.mp4" type="video/mp4">
                           <source src="video/ejemplo.ogg" type="video/ogg">
                           Tu navegador no soporta el elemento de video.
                           </video>

<iframe>

La etiqueta <iframe> permite incrustar contenido externo dentro de una página web, como videos de plataformas en línea, mapas interactivos o incluso otras páginas web completas.

Funciona como una ventana dentro del sitio principal. Utiliza el atributo src para indicar la dirección del contenido que se va a mostrar, y puede incluir atributos como width y height para definir sus dimensiones.

Ejemplo de uso:

Código HTML (YouTube):
                          <iframe width="560" height="315" 
                          src="https://www.youtube.com/embed/ID_DEL_VIDEO" 
                          title="Video de YouTube" 
                          frameborder="0" 
                          allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
                          allowfullscreen>
                           </iframe>
