Aprende sobre las etiquetas de formularios en HTML y su importancia para recopilar información del usuario.

Introducción a las Etiquetas de Formularios

Los formularios en HTML se usan para recopilar información del usuario. Sirven cuando necesitas que el usuario ingrese datos como su nombre, correo electrónico, contraseña o cualquier otra información relevante.

Tipos de input

La etiqueta <input> puede tener diferentes tipos como texto, número, contraseña, etc. Cada tipo tiene su propia funcionalidad y uso específico dentro de un formulario HTML.

text

El tipo <input type="text"> permite ingresar texto. En este ejemplo escribiremos el nombre de una mascota y lo mostraremos en pantalla.

Ejemplo de uso:

Código HTML:
                    <label for="mascota">Nombre de la mascota:</label>
                    <input type="text" id="mascota">
                    <button type="button" onclick="mostrarMascota()">Mostrar</button>
                    <p id="resultadoMascota"></p>
Resultado:

El tipo <input type="email"> permite ingresar un correo electrónico.

Ejemplo de uso:

Código HTML:

                    <input type="email" id="correo">
                    <button type="button" onclick="mostrarCorreo()">Mostrar</button>

Contraseña

El tipo <input type="password"> permite ingresar una contraseña. Aquí validaremos que no esté vacía y mostraremos la longitud de caracteres.

Ejemplo de uso:

Código HTML:
                    <label for="password">Contraseña:</label>
                    <input type="password" id="password" placeholder="Escribe tu contraseña">
                    <button type="button" onclick="mostrarPassword()">Mostrar</button>
                    <p id="resultadoPassword"></p>

El tipo <input type="number"> permite ingresar números. En este ejemplo validaremos que la edad esté entre 1 y 120.

Ejemplo de uso:

Código HTML:

                    <input type="number" id="edad" min="1" max="120" placeholder="Ingresa tu edad">

Ejemplo de uso:

Código HTML:
                    <form id="formArchivo">
                        <label for="miArchivo">Selecciona una imagen:</label>
                        <input type="file" id="miArchivo" accept="image/*">
                        <br><br>
                        <input type="submit" value="Enviar">
                    </form>
                    <p id="mensajeArchivo"></p>
                    <img id="vistaPrevia" style="max-width:200px; display:none;">
